Selected Project

auto-log

2026 — ongoing

Spring Boot 4 · Java 21 · Vue 3 · PostgreSQL · Flyway

  • A garage and vehicle maintenance log built for a fleet of JDM imports — a constraint that drove most of the design. Odometer units are a property of the car, not a user preference, so every reading stores both what the cluster displayed and a generated miles column; cost-per-mile stays comparable across a mixed garage.
  • The log has two audiences. Purchase price, import duty and standing costs are private records; a buyer's history sheet is built so those are structurally excluded rather than filtered out — the disclosure boundary lives in the schema, not in a checkbox someone can forget.
  • Reminders are rules, not records: a rule stores no "last done" date, because one rule can cover the whole garage. The anchor is the newest linked maintenance record on that vehicle, so logging the work is what satisfies the reminder.
  • Split API and SPA rather than a monolith, so a planned Capacitor mobile client shares the same client-agnostic endpoints.
